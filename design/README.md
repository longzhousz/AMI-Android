# AMI 图标

[ami-icon.svg](ami-icon.svg) 是可编辑的源图：珍珠白底、墨蓝双音符、五条清晰的唱片纹路。没有字体、链接图片或模糊滤镜。

在仓库根目录运行 `python3 tools/generate_icon.py`，生成 Android 原生矢量背景、前景、系统主题图标及通知音符。仅需 Python 标准库；修改 SVG 后将生成结果一起提交。转换器只处理此图使用的路径、渐变和简单变换。

桌面图标由系统裁切为圆形或圆角方形，源图的圆角不烘焙进 Android 资源。108 dp 自适应图层留出系统裁切与视差空间；主体保持在安全区域内。系统主题图标和通知只保留音符轮廓，确保小尺寸可读。

需要 PNG 时，可使用 Inkscape 导出 SVG；应用本身不打包高分辨率 PNG。
