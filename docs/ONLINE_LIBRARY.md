# 在线曲库与音质：0.1.14

应用版本 0.1.14 / versionCode 15 / SQLite schema 4。基于已在本地试用的 0.1.13（`fa6c5e1`）；本轮用户没有电脑，不连接手机。

## 使用

云端交付构建为 `musicPreview`，包名 `com.longzhousz.ami.musicpreview`，显示名 AMI。安装后，在官方网易云 HTTPS 页自行登录，点击「完成登录」。账号、歌单、歌词和音频均由手机直接请求，运行无需电脑、root 或网易云 App 后台随播。

本包使用独立包名，可与本地签名的「AMI 网易云」0.1.13 并存。签名不同不能覆盖安装，因此首次需要重新登录、按需重新设置翻译密钥；旧安装的数据完整保留。不要卸载或清除旧应用来解决签名冲突。持有原本地签名的开发者可以继续构建 `neteasePreview` 更新原包。

```sh
./gradlew testDebugUnitTest lintDebug assembleMusicPreview
```

Windows 使用 `gradlew.bat`。APK 位于 `app/build/outputs/apk/musicPreview/app-musicPreview.apk`。

## 布局

- 曲库：收藏专辑和自己创建的歌单混排，统一用封面网格展示。没有歌曲／专辑视图切换、分类 chips 或右上角的刷新与账号按钮。网易云的红心歌单和别人创建的收藏歌单不混入这张书架。
- 下拉刷新：重新获取目录，并随机重排卡片；多于一张卡片时避免刷新后仍完全同序。歌单、专辑内部曲序和正在播放的队列不变。
- 我喜欢：按网易云红心歌单中的原顺序显示歌曲。与旧本地收藏分开，不改变账号的喜欢状态。
- 搜索：保留曲库顶部的网易云歌曲／艺人搜索；不是本地曲库过滤。
- 专辑、歌单和红心列表每次读取 30 首，滑动接近末尾自动续载。播放队列仍取点击时已载入的可用歌曲，最多 1,000 首；后续分页与书架刷新不会改变正在播放的队列。
- 底栏：曲库、我喜欢、设置三个图标，不显示文字；保留无障碍名称。账号位于设置；原有歌词播放页、封面转场和迷你播放器继续复用。
- 本地音乐：设置中「浏览本地音乐」进入原曲库与本地喜欢。源文件、文件夹授权、收藏、译文和曲序保留；在线首页不预先加载整个本地曲库。恢复本地播放或进入本地入口时才加载。

目录在当前 ViewModel 生命周期内保留，切换标签不重复抓取。网络异常保留已有目录并提供重试；不增加后台周期同步或性能面板。目录本身不写音频缓存。

## 音源与播放

优先级为账号有权播放的 **高清臻音 `jyeffect` → Hi-Res `hires` → 无损 `lossless` → 极高 `exhigh`**。不会主动请求更高会员档位。优先使用网易云客户端音源协议，协议不可用时兼容原网站音源接口；保留旧 HQ 兼容请求。使用公开协议独立实现，参考资料与许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)，不依赖第三方代理服务。

音质判断读取服务器实际返回的 `level`、`type` 和 `br`，不使用请求档位充当结果。高档响应已经给出下一档或更好的音源时不再重复探测；降档时保留目前最佳的有效音源。AAC／MP3 响应不能冒充无损，未知编码不会标记成高档音质。核对原歌曲 ID、CDN 域名、HTTPS、试听字段与时长；已识别的试听片段不播放，拒绝外部替换音源。登录过期会停止探测并提示重新登录。

Media3 启用高精度 PCM 浮点输出支持，适用时减少高位深音源在应用输出环节的精度损失。它不保证系统、蓝牙链路或耳机以相同采样率／位深输出，也不意味着网易云特定空间渲染已复现。`jyeffect` 包含听感处理，产品档位顺序不等于所有歌曲的保真程度排序。

后台 `AmiAudio` 日志仅记录音源的响应档位／编码／码率，以及解码器输入的格式／采样率／声道／PCM 标识；不记录会话、播放地址、私人歌单、歌词、曲名或文件路径。输入格式日志不能当作实际硬件输出或耳机端音质的证明。前台不增加诊断数据。

## 验证边界与后续真机验收

本轮新增已知协议向量、固定 HTTPS 请求、档位回落／错误音质声明／试听拒绝、封面卡片重排、收藏专辑和自建歌单隔离、红心列表、专辑分页与搜索的自动化覆盖。模拟器使用合成账号与 HTTP 夹具，不访问真实会员会话，也不代表真实网易云音源、vivo 输出或耳机空间效果已通过。

无登录态的公开端点连通检查收到了正常 JSON，示例音源无可用地址；该结果只说明协议请求可达，不能说明用户的 VIP 音质权限。本轮不索取或上传用户的 Cookie。

以后有电脑时，本地 Codex 可在授权的 X300 上：

1. 先读 `AGENTS.md`，核对 ADB 目标、系统、已有包名和签名。保留所有原安装与数据，不运行会修改日常曲库的完整仪器套件。
2. 用户在试用包内自行登录，选择 3–5 首官方 App 可选高清臻音的相同歌曲 ID；保持同一耳机与相同音量，比较实际音源与听感。
3. 使用 `adb -s YOUR_SERIAL logcat -d -s AmiAudio` 核对响应档位与解码输入；必要时只采集音频输出状态，检查混音、重采样与蓝牙编码。不要抓取或输出 Cookie、临时 URL 或私人响应正文。
4. 检查下拉仅重排卡片、红心列表内容、分页、歌词时间轴、拖动进度、连续切歌和熄屏播放。拔掉 USB、关闭电脑后重复播放，确认运行独立于电脑。

网易云网站与客户端协议会变化。最终可用音源由账号、具体歌曲、地区和服务端决定，不能承诺所有歌曲均达到高清臻音或与官方客户端空间效果相同。
