# 播放页下拉与封面缓存：0.1.16

应用 0.1.16 / versionCode 17，本地曲库 schema 4、在线音频缓存 schema 1 保持不变。继续使用 `musicPreview`、`com.longzhousz.ami.musicpreview` 和既有云端签名，覆盖云端 0.1.15 时保留登录、曲库和设置。本轮不连接 X300。

## 下拉交接

0.1.15 的浮动迷你播放条仍在背景绘制，播放页转场末尾又绘制了一份相同内容。浮动布局增加外侧留白后，第二份播放条的左边距和宽度与原条不一致，收起时出现重影和位置跳动。

0.1.16 保留原条布局以测量目标位置，但动画期间隐藏其绘制。转场末尾的画面按目标 `bounds` 的左边、宽度和高度显示，最终交还原条；原播放页在末段提前淡出，迷你条随后清晰接上；不保留整块空白底色和全尺寸投影，避免空白尾部或旧按钮残影。继续使用可打断的弹簧，末尾画面也能接住向上的反向拖动。

系统导航栏的对比度背景始终关闭，避免展开／收起时突然增加或移除系统遮罩。状态栏、导航栏的图标颜色分别按播放页面实际覆盖到的位置切换，只在跨过各自边界时更新；不因每一帧拖动重建布局。

## 封面形状与复用

- 歌曲行移除外层圆角裁切，完整保留左侧方形封面的四个角。歌曲行维持列表布局。
- 只有底部迷你播放条的缩略图使用 9 dp 圆角，与其 20 dp 圆角卡片匹配。专辑网格、专辑详情和歌词播放页中的原图不额外加圆角。
- 只在图片被请求显示时下载原图。列表、封面转场和背景取色经同一个 Coil 加载器，按图片 URL 共用原始文件；相同 URL 的并发请求合并，不额外启动整库抓图或预取任务。
- 缓存按最近使用时间保留一周，内存命中也会续期；下次启动或后续图片请求时清理超过一周未使用的文件。网络下载复用现有 HTTPS 域名、响应类型、大小与超时限制，并校验图片可解码后原子保存，不重新压缩原图。
- 缓存命中直接解码本地文件，移除额外的图片加载渐显；封面切换与整体转场仍保留。下载失败不落盘；剩余空间不足时仍可显示本次图片，但暂停新增磁盘副本。系统自身仍可以回收 Android 的应用缓存。

## 常听歌曲缓存上限

设置 → 存储与隐私 → 常听歌曲缓存上限，可选择 256 MB、512 MB、1 GB、2 GB、4 GB、8 GB，默认 512 MB，选择持久保存。仍沿用近七天三次有效收听、闲置七天回收、允许移动网络、单首最多 256 MiB、保留至少 1 GiB 剩余空间的规则。

降低上限时在 IO 线程先回收较久未听的在线副本，正在播放的文件保留到切换／结束后再补齐清理。进行中的下载在提交时重新检查最新限额；不会为了降低容量改动音质或导入音乐。不增加任务列表、缓存进度或本地／在线标志。
