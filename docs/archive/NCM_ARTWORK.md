## 行为

部分 NCM 只在元数据的 `albumPic` 中保存封面网址，容器与内部音频均没有图片。此前应用只读取本地图片，因此这些歌曲显示占位封面。

导入或「设置 → 重新扫描」时，按以下顺序选择可解码的图片：

1. 音频内嵌图片。
2. NCM 容器图片。
3. 音频同目录中现有规则支持的 `cover`、`folder`、`front` 图片。
4. NCM 元数据中的准确 `albumPic` 网址。

空白或损坏的图片不会遮蔽后续来源。联网只允许网易云 `p数字.music.126.net` 图片域名，HTTP 地址转换为 HTTPS；不携带 API Key、不跟随重定向、不按歌名搜索，也不上传音频、歌词或本地路径。隐私说明已同步更新。

下载在 IO 线程执行，支持取消，限制 8 MiB、连接/读取超时和总读取时长；可解码图片沿用现有缩图、JPEG 缓存和原子落盘。相同网址复用磁盘缓存；当前扫描中无法连接的主机暂停重复请求，其他图片主机仍可继续。失败保留音频导入结果，下次重新扫描可重试，没有新增周期轮询。

## 现有曲库

旧的缺图 NCM/CUE 扫描记录会重新检查封面；已有正常封面的记录继续使用原指纹。没有有效图片网址的记录完成检查后也保持增量复用，避免每次重读。下载失败不会写成成功缓存。

没有改动数据库 schema、歌曲标识或源文件。收藏、曲序、首次导入时间、歌词、已有译文与保存队列沿用原数据。

## 安装与复现

日常 `com.longzhousz.ami.preview` 保留；真机验证使用并存的 `com.longzhousz.ami` Debug 包。本机签名与原预览版不同，覆盖原预览版需要原签名密钥，不通过卸载或清除数据处理冲突。
