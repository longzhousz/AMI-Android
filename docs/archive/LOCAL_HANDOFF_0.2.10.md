# AMI 当前交接

当前版本 **0.2.10 / versionCode 32**，最低 Android 13，数据库 schema 6、在线音频缓存 schema 1 与签名不变。应用源码 `7caab953db6bfdecca8687bbf0469547ac8851c0`，之后的提交只更新交付文档。上一版证据见 [0.2.9 交接](LOCAL_HANDOFF_0.2.9.md)。

## 本轮修改

网易云封面按原图路径统一缓存身份，忽略 CDN 分片主机和 param 尺寸参数，其他查询参数保留；下载仍使用原地址的主机，移除缩略尺寸，保留一份原图和已有有界轻量预览。同图并发请求合并，列表、专辑与播放页复用相同内存键。失败的可见封面只在有新预览可用时恢复，不新增轮询或整库预取；缓存损坏后允许重新获取。

专辑元数据在内存以最多 512 项记录准确专辑 ID 与封面地址。歌曲缺少封面时复用该专辑的已知地址；专辑详情也以所在专辑补全缺失项，歌单封面不套用到歌曲。登录／退出时清空元数据索引，原有一周保留与低存储保护不变。

播放模式菜单只保留列表循环、单曲循环、随机播放三个标题。旧版顺序播放偏好恢复时转为列表循环；私人 FM 的内部排队行为保留。今后选择菜单默认只展示标题，必要说明放详情。

曲库首页删掉“曲库”大标题，搜索／发现按钮悬浮于列表上方，玻璃采样滚动内容；首屏为按钮留出空间，滚动后封面可从按钮下穿过。详情与搜索仍保留标题和返回入口。设置首页删掉“设置”标题，子菜单标题与返回保留。
