# 应用更新

从 0.2.3 的云端在线版开始，AMI 在进入前台时安排一次 GitHub 最新正式发布检查。紧接着从系统权限页／安装器返回不重复检查；已在运行的同名任务继续完成。不增加周期任务、下载进度页面或通知。

来源固定为公开仓库 longzhousz/AMI-Android 的 Releases。只选择更高版本的 online-preview.apk，不选择草稿、预发布、其他构建或来源；不包含 GitHub 登录令牌。新包在后台下载，失败保留已验证的缓存，下次启动再试。

下载按官方 SHA-256（或同一发布的 SHA256SUMS）核对完整文件，再核对本应用包名、同一签名、更高 versionCode、对应版本名及设备最低系统。重定向仅允许 GitHub 官方 HTTPS 对象地址。复制及校验在 IO 线程，已下载相同包不重复下载；更新目录通常只保留当前包，切换版本时暂留前一份供系统读取，后续检查清理。升级成功后回收已安装的旧包。不触及音乐、封面或用户数据。

新版下载就绪后，用户进入设置才出现「发现新版本」弹窗。播放器、聆听报告及其他设置弹窗覆盖时暂不提示；同一版本每次应用进程最多提示一次。「稍后」保留已下载的包，下次启动后进入设置可以再次询问。「安装」才调用 Android 的系统安装流程；首次可能需要用户允许 AMI 安装应用，系统仍需用户确认安装。

FileProvider 仅开放应用私有 updates 目录，授予安装器临时读取权限，不分享文件路径。Debug／其他历史构建不自动检查 online-preview 包；测试使用独立夹具和模拟器，不覆盖用户安装。
