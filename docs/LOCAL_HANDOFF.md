当前版本 **0.2.9 / versionCode 31**，最低 Android 13 / API 33，compile / target API 37。数据库 schema 6、在线音频缓存 schema 1 不变。应用源码 `a65857597fc7174f701d9cf220a07a1c65bca995`，之后的提交只更新交付文档。上一版的交付与验证保存在 [0.2.8 交接](archive/LOCAL_HANDOFF_0.2.8.md)。

## 设置整理

首页收敛为网易云账号、我的聆听、歌词与翻译、外观、本地音乐、存储与数据、更多设置七个入口；“我的聆听”保持直接入口。首页和子菜单的操作行只显示图标、标题和箭头，保留玻璃分组，去掉图标外的独立装饰框。版本信息放在“更多设置”底部，首页不留容易在悬浮栏上方裁切的页脚。

翻译、导入、缓存／备份、隐私／高级功能分别进入子菜单。账号状态、密钥用途与加密说明、当前翻译模型、缓存大小和文件数、清理范围、导入支持格式与授权说明、记录保留范围均在对应详情或子菜单中保留。主题与缓存上限在单选详情中显示当前选择。

子菜单复用现有页面切换动效，顶部返回与系统返回回到设置首页。对话框返回先关闭对话框，仍在原子菜单；子菜单的返回回调在弹窗关闭期间保持有效，避免连续两次返回跳出设置；从本地曲库返回保留本地音乐子菜单。首页不读取歌词统计或遍历缓存目录，打开对应功能后按需读取。更新安装提示仍只在设置可见且没有覆盖窗口时出现，并避开子菜单。

现有登录、播放、导入、翻译、备份合并规则和自动缓存行为不变。使用路径见 [使用说明](USER_GUIDE.md)。
