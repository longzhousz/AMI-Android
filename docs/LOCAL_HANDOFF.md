# AMI 当前交接

当前版本 **0.3.4 / versionCode 41**，最低 Android 13，包名为 `com.longzhousz.ami.musicpreview`。

- 未登录时可在首页登录网易云或导入本地音乐；导入后可在曲库切换本地与网易云。
- 本地曲库支持专辑和歌曲视图、搜索、收藏与曲序；专辑保留封面转场和透明状态栏体验。
- 播放页长按翻译按钮可选择 AI 翻译或网易云译文。
