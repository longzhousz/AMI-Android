# AMI 当前交接

当前开发版本 **0.1.19 / versionCode 20**，交接分支 `main`，本地曲库 schema 5、在线音频缓存 schema 1。整理日期：2026-10-30。

## 本轮范围

实现设置页直接可见的「我的聆听」，不是折叠分组里的入口。周、月、年纵向图鉴包括总览、时长趋势、日历、歌曲前十、歌手占比、专辑偏好、作息热力图和初遇／重逢；只从新版后的 AMI 播放积累，长期保存轻量数字汇总。口径、存储与边界见 [我的聆听](MY_LISTENING.md)。

播放服务复用十秒检查点，单调时钟计时，小批事务后台写入；报告按需查询，退出释放，不新增定时任务、依赖、权限或统计网络接口。设置导航页 6 独立处理，只有本地页 4/5 可触发本地曲库加载。

元信息增加可选主艺人／专辑标识，旧队列可恢复；统计表不与歌曲删除级联。缓存清理、删文件与换账号保留历史，确认清除统计只影响统计表。沿用 `com.longzhousz.ami.musicpreview` 和原签名构建，发布前核对实际 APK。

## 验证状态

本地首轮 87 项 JVM 测试、Lint、Debug 和仪器测试 APK 编译通过。最终应用代码、双系统设备回归、三年规模证据与分发包身份将在本轮完成时登记；当前不能把开发过程的检查视为最终安装包验收。

没有连接 vivo X300。模拟器合成数据可以检查计时、存储、界面和播放流程，不能证明用户真实账号、真机手感、续航、耳机输出或原子岛已经通过。

## 开发与数据

先读根目录 [AGENTS.md](../AGENTS.md)、[本地开发](LOCAL_DEVELOPMENT.md) 与 [使用说明](USER_GUIDE.md)。保持前台简洁，不增加翻译任务列表、生成进度、生成时间、模型记录或性能面板。统计图表自己的数字说明属于用户明确要求的收听总结。

保留原有专辑原图、封面回看、逐字歌词、FM、共享封面转场和单窗口播放页下拉。音乐缓存仍只回收 AMI 在线副本，不删除导入音乐、NCM 转换结果或译文。签名冲突不能通过卸载或清数据解决。
