# AMI 当前交接

当前版本 **0.3.10 / versionCode 47**，最低 Android 13，包名为 `com.longzhousz.ami.musicpreview`。

- 未登录时可在首页登录网易云或导入本地音乐；导入后可在曲库切换本地与网易云。
- 本地曲库支持专辑和歌曲视图、搜索、收藏与曲序；专辑保留封面转场和透明状态栏体验。本地右上角不再放菜单，最近导入和随机播放入口已移除。
- 补 CUE 接管整轨时保留收藏、手排曲序和手动歌词；底部「我喜欢」可直接查看本地收藏，两种来源并存时提供「本地／网易云」切换。
- 网易云歌单与收藏专辑分别加载、分别重试；在线队列记录账号归属，换号恢复只载入本地曲目，退出登录清理在线队列与 FM 续接状态。
- 播放页首次点击翻译按钮默认取网易云译文，长按可选择 AI 翻译或网易云译文。
- 本地与网易云曲库共用卡片网格、封面转场和回顶逻辑。双击底栏「曲库」会退出详情或搜索，先回到当前来源顶部，再刷新数据。
- 本地与网易云共用专辑详情，封面下显示歌曲数和总时长。被省略的专辑名可点开。本地返回保留原卡片位置，搜索键盘不会自动重新打开。

- 在网易云曲库长按「网易云」可选择收藏专辑排列。初始使用网易云返回的顺序。选择「随机」会重新排列并刷新收藏专辑。
- 同一队列内重选曲目时直接跳到所选歌曲的开头。曲序或媒体条目改变时载入新列表。

格式、静态分析、137 项 JVM 单测、Lint、Debug 与 MusicPreview 构建通过。专用 Android 36 模拟器通过 49 项相关仪器测试。发布 APK 以同一签名从 0.3.9 覆盖安装，验证原曲库可读取、本地来源没有长按排序操作、切到网易云后可打开菜单，所选顺序在进程重启后保留。网易云使用接口夹具，真实网易云账号与真机未验证。
