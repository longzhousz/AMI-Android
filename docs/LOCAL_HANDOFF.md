# AMI 当前交接

当前版本 **0.3.6 / versionCode 43**，最低 Android 13，包名为 `com.longzhousz.ami.musicpreview`。

- 未登录时可在首页登录网易云或导入本地音乐；导入后可在曲库切换本地与网易云。
- 本地曲库支持专辑和歌曲视图、搜索、收藏与曲序；专辑保留封面转场和透明状态栏体验。
- 补 CUE 接管整轨时保留收藏、手排曲序和手动歌词；底部「我喜欢」可直接查看本地收藏，两种来源并存时提供「本地／网易云」切换。
- 网易云歌单与收藏专辑分别加载、分别重试；在线队列记录账号归属，换号恢复只载入本地曲目，退出登录清理在线队列与 FM 续接状态。
- 播放页首次点击翻译按钮默认取网易云译文，长按可选择 AI 翻译或网易云译文。

验证范围：格式、静态分析、JVM 单测、Lint、Debug 与优化版构建；专用 Android 36 模拟器运行与本次改动相关的仪器测试（CUE 接管、本地收藏入口、在线曲库分别加载、在线队列账号隔离、在线曲库内容与播放存储），并安装优化版完成启动冒烟。完整设备套件、真实网易云账号、真机听感与真实新版覆盖安装未验证。
