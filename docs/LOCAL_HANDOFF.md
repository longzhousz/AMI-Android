# AMI 当前交接

当前版本 **0.2.3 / versionCode 25**，最低 Android 13 / API 33，compile / target API 37。应用源码 `9b0dd1ea5e9ea0c38e608b4a2353a57a52e75a7c`；后续提交仅更新验证文档或模拟器配置。本地曲库 schema 5、在线音频缓存 schema 1 不变。

## 专辑连续展开

0.2.2 为了隔离详情访问，把源卡片的共享封面标识也随点击更换，导致共享动画丢失起点。0.2.3 恢复按专辑稳定的共享标识；访问 ID 只重建详情列表，不改变源封面标识。每次进入仍从顶部开始，曲库网格位置、近期专辑内容缓存和不显示详情转圈的规则保留。

同一组可控 Compose 时钟截图检查中，旧版的封面宽度从 453 px 直接跳到 649 px，80 ms 时已等于终态。修复后依次为 **453 → 495（80 ms）→ 591（160 ms）→ 649 px**，重复进入两次结果一致。还保留滚动后重进和快速返回反转的回归。这些是模拟器中间帧位置证据，不是 vivo 真机帧率测量。

## 安静的应用更新

安装本版后，进入前台会安排 GitHub 最新正式发布检查，系统权限页／安装器短时返回不重复安排。复用 WorkManager 的一次性任务，不新增周期轮询、下载通知、任务页或进度面板；不需要 GitHub 登录令牌。

只选择固定公开仓库的更高版本 online-preview.apk。后台核对完整 SHA-256、包名、相同签名、更高版本及设备最低系统后缓存；同一文件不重复下载。下载失败保留已验证的旧包，未完成文件不作为可安装包。更新文件仅位于应用自己的 updates 目录，切换版本时短暂保留前一个供系统读取，后续检查和升级后回收。

仅在设置可见、未覆盖播放器／其他设置弹窗时询问安装；同一版本每个应用进程最多提示一次。「稍后」保留安装包，下次启动可再询问。「安装」才申请必要的系统安装来源权限，并通过受限 FileProvider 调用系统安装器。系统仍要求用户确认，没有静默安装。详见 [更新规则](APP_UPDATES.md)。
