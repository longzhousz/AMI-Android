# AMI 当前交接

当前开发版本 **0.1.18 / versionCode 19**，交接分支 `main`，本地曲库 schema 4、在线音频缓存 schema 1 保持不变。整理日期：2026-10-29。

## 本轮范围

用户明确要求优化曲库快速回滚时的封面显示，并落实逐字歌词、发现新歌和专辑封面转场。此前缓存升级音质、弱网、锁屏耳机的建议不作为本轮主线。

封面采用有界已浏览预览与高清缓存复用，缓存命中绕过无关下载锁；YRC 附加真实词时间并保留原 LRC 索引；私人 FM／每日推荐共用一个图标入口；网格与详情共享封面、返回保留滚动状态。实现、接口依据与验证边界见 [本轮体验说明](LISTENING_EXPERIENCE.md)。

运行仍只需要手机，不要求 root、电脑连接端、第三方代理或开放平台私钥。沿用 `com.longzhousz.ami.musicpreview`，计划使用原云端签名覆盖更新，保留账号、设置、曲库与译文。发布前仍需核对实际产物，下载入口为 [最新发布](https://github.com/longzhousz/AMI-Android/releases/latest)。

## 验证状态

本地 79 项 JVM 测试与 Lint 已通过，Debug 和仪器测试 APK 编译通过；本轮双系统设备回归与优化包验证进行中，完成后在此登记源码和交付摘要。只有实际执行的检查才写为通过。

当前没有连接 vivo X300。模拟器与合成媒体不能证明真实账号推荐、各歌曲 YRC 覆盖率、手机帧率、耗电、实际耳机输出或原子岛已验收。用户此前反馈 0.1.17 体验良好，不替代新版本验收。
