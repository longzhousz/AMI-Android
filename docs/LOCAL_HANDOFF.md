# AMI 当前交接

当前版本 **0.4.4 / versionCode 52**，最低 Android 13，包名为 `com.longzhousz.ami.musicpreview`。

- 未登录时可在首页登录网易云或导入本地音乐；导入后可在曲库切换本地与网易云。
- 本地曲库支持专辑和歌曲视图、搜索、收藏与曲序；专辑保留封面转场和透明状态栏体验。本地右上角不再放菜单，最近导入和随机播放入口已移除。
- 补 CUE 接管整轨时保留收藏、手排曲序和手动歌词；底部「我喜欢」可直接查看本地收藏，两种来源并存时提供「本地／网易云」切换。
- 网易云歌单与收藏专辑分别加载、分别重试；在线队列记录账号归属，换号恢复只载入本地曲目，退出登录清理在线队列与 FM 续接状态。
- 播放页首次点击翻译按钮默认取网易云译文，长按可选择 AI 翻译或网易云译文。
- 本地与网易云曲库共用卡片网格、封面转场和回顶逻辑。双击底栏「曲库」会退出详情或搜索，先回到当前来源顶部，再刷新数据。
- 本地与网易云共用专辑详情，封面下显示歌曲数和总时长。被省略的专辑名可点开。本地返回保留原卡片位置，搜索键盘不会自动重新打开。

- 在网易云曲库长按「网易云」可选择收藏专辑排列。初始使用网易云返回的顺序。选择「随机」会重新排列并刷新收藏专辑。
- 同一队列内重选曲目时直接跳到所选歌曲的开头。曲序或媒体条目改变时载入新列表。

- 网易云排序菜单与发现菜单共用液态玻璃。弹窗按实际屏幕位置采样曲库内容，保留封面颜色并淡化底层细节。界面变更遵循 [界面设计规范](UI_DESIGN.md)。

网易云曲库和「我喜欢」的顶部放大镜支持个人搜索。指南针里的「网络搜索」查询网易云全站。使用方式见 [使用说明](USER_GUIDE.md#曲库与我喜欢)。

曲库和「我喜欢」的浏览顶栏可随手势收展。向列表深处浏览时收起，朝顶部回滑时恢复。

本地专辑至少有三首歌才显示「曲序」。网易云作词和作曲署名显示为文字，普通歌词只有无时间轴的署名时优先使用可用的逐字歌词。

本地与网易云个人搜索共用悬浮玻璃搜索框和展开动效。网易云个人曲库搜索优先匹配已读曲目，并行读取缺少的来源。歌曲详情最多每批 90 首。

格式、静态分析、143 项 JVM 单测、Lint、Debug 和 MusicPreview 构建通过。19 项 Android 36 模拟器回归覆盖搜索悬浮、分页、缓存复用、失败重试、账号隔离和曲库回归。网易云使用接口夹具。200 首歌的歌单读取使用三次歌曲详情请求，缓存有效期间更换关键词无新增请求。优化包从 0.4.3 同签名覆盖安装并启动。
