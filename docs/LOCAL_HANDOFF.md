# AMI 当前交接

当前版本 **0.2.2 / versionCode 24**，最低 **Android 13 / API 33**，compile / target API 37。应用源码 `57d00f40dab6c831e4d79fc6d4c3accfff875ee5`；后续提交仅整理交付文档。本地曲库 schema 5、在线音频缓存 schema 1 保持不变。

## 本轮范围

「我喜欢」改为整页沉浸式深色。顶部最多 30 张近期红心歌曲封面统一倾斜、紧密拼接并渐隐到歌曲列表，原图保持方形；去掉白色相框、单张随机旋转和重复操作栏。状态栏、底部悬浮导航和迷你播放条同时采用适合深色页面的配色。封面来自已载入的歌单前缀，按显示需要沿用现有图片缓存，不整库预取；歌曲行仍不显示红心。

专辑／歌单每次打开创建独立访问和滚动状态，从顶部完整展示封面，不恢复上一次详情位置；返回曲库仍保留网格位置。共享封面按本次访问匹配，退出中的旧详情保留自己的状态，避免快速返回、重进时用到旧坐标。

专辑内容另外保留在估算预算 1 MiB 的内存 LRU 中，最长七天；切换专辑不再只保留最后一份详情，手动下拉可绕过缓存。刷新指示只在曲库和「我喜欢」主页显示，详情／搜索不显示；不新增磁盘副本或后台刷新，进程回收、账号变化后按需重新读取。

播放队列改为弹层窗口内独立的封面配色背景，沿用播放器深色，玻璃按钮只采样本窗口；移除整个移动面板的跨窗口采样。每次打开重新创建原生弹层状态，关闭动画被手势取消后释放标记；动画完成到隐藏状态时移除弹层，避免透明窗口挡住操作。保留拖动、系统返回、关闭图标、选歌和网易云红心同步。长队列按需显示，并从当前歌曲附近打开。

沿用 Backdrop 1.0.6、专辑与播放页流动光晕、单窗口播放页下拉、歌词、音质、聆听图鉴和缓存策略。没有修改账号协议、数据库或音源权限。手机独立运行。
