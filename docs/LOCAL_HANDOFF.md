# AMI 当前交接

当前版本 **0.1.20 / versionCode 21**，交接分支 `main`，本地曲库 schema 5、在线音频缓存 schema 1。整理日期：2026-10-30。

## 本轮范围

修复“已登录、有 VIP，部分歌曲仍无法播放”的两处请求兼容问题：客户端播放端点报登录类错误、拒绝请求或未给出完整音源时，先用相同登录会话尝试固定第一方网页端点；后续音质探测遇到接口拒绝或网络失败时，保留此前已取得的可用音源。正常情况仍优先高清臻音 → Hi-Res → 无损 → 极高，最多五次 v1 请求及一次原有 HQ 回退。

客户端端点的 301／403 不足以证明网页登录失效。网页登录确实失效时立即停止；错误歌曲、非许可域名、试听或不完整音源仍拒绝，不使用匿名会话或替换音源。请求参数不充当实际音质证据。

播放失败分别提示登录过期、只有试听、接口拒绝、音频服务器、网络和格式错误。媒体服务保留一条当前歌曲的固定提示，本机控制器据此显示；新增诊断只记错误码和异常类型，不输出原始异常消息、Cookie、播放地址或私人歌单。

保留 0.1.19 的「我的聆听」及原有界面、歌词、音质显示与缓存，不新增面板、开关、依赖、权限、数据库迁移或周期任务。
