# AMI 当前交接

当前版本 **0.1.21 / versionCode 22**，分支 `main`，本地曲库 schema 5、在线音频缓存 schema 1。整理日期：2026-10-30。

## 本轮范围

在线歌曲支持添加／取消网易云红心。封面页、歌词页、搜索／歌曲列表和队列共用账号状态，沿用图标按压与切换动画，填充红色表示已喜欢。操作发送到 AMI 当前登录的网易云账号；原版 App 刷新后可查看，原版改动可在 AMI 手动刷新同步回来。

首次读取与手动刷新 `song/like/get`；显式点按提交 `radio/like`，使用原会话、固定第一方 HTTPS 与现有请求加密。ID 校验和账号快照在网络前确认；不读取其他应用 Cookie，不需要开放平台私钥、电脑或 root。

`NeteaseLikes` 管理一份内存持久集合、即时反馈、失败回退、同曲去重和账号世代隔离，网络串行，最多 16 个待处理动作。不会产生新的本地数据库、周期任务或离线写入队列。未知状态加载后才允许修改，异常提示使用固定文字；旧账号迟到的数据和错误不会修改新账号。

写入成功只修补已载入的「我喜欢」前缀、分页 offset 和对应 ID 缓存。保留列表位置，不重新请求整页，不重建播放 catalog、不换歌、不改队列；红心变化不会触发歌词重载。本地音乐仍保留本地收藏，0.1.20 的播放兼容修复、高音质优先、聆听图鉴和原有动效继续保留。
