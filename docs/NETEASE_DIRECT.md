# 网易云应用内播放（0.1.13）

> 0.1.14 已将在线内容整合到主界面的「曲库」「我喜欢」，并改进音质请求；使用方式见 [ONLINE_LIBRARY.md](ONLINE_LIBRARY.md)。下文界面和真机记录对应 0.1.13，不能代替新版音质与布局验收。

此版本满足「只用手机，在 AMI 看自己的歌单并直接播放」的使用方式。用户在 AMI 内嵌的网易云官方 HTTPS 页面自行登录，确认后由 AMI 读取歌单、搜索和歌词，使用现有 Media3 播放器播放。无需电脑服务、root、网易云 App 后台播放或开放平台私钥。

## 安装与使用

1. 构建 `./gradlew assembleNeteasePreview`（Windows 使用 `gradlew.bat`）。产物为 `app/build/outputs/apk/neteasePreview/app-neteasePreview.apk`，显示名「AMI 网易云」，包名 `com.longzhousz.ami.neteasepreview`，应用版本 0.1.13 / versionCode 14。
2. 保留原 AMI 安装。新包名可并存，但不共享曲库、文件夹授权、账号或签名；更新此包也需要相同签名，不用卸载或清除数据解决冲突。
3. 打开「登录网易云」，在官方网页完成登录，再点击 AMI 顶部的「完成登录」。密码和验证码由用户在官方页面输入，无需交给开发助手。
4. 查看「全部」「我喜欢」「我创建的」「我收藏的」歌单，或搜索歌曲。歌单内每次读取 30 首，点击「加载更多」继续读取。
5. 点击有播放权限的歌曲，进入 AMI 原有播放页。歌词按网易云原歌曲 ID 获取；服务端提供时间轴时可以滚动和点句跳转。顶部账号按钮可重新登录或退出登录，刷新按钮重新读取歌单。

Debug、Preview 和 Release 的网易云入口也使用该路径；`phonePreview` 保留旧随播启动方式，`cloudPreview` 保留 Windows 连接端试验。它们的验证记录不能互相替代。

## 账号与数据

用户已明确同意在 AMI 内的官方登录页登录，并在点击「完成登录」后保存本次应用会话。AMI 只从自身 WebView 的 `music.163.com` 会话中保留所需 Cookie，验证账号后使用 Android Keystore AES-GCM 加密写入不备份目录。登录网页关闭后清理本应用的网页 Cookie；不会读取网易云 App、浏览器或其他应用的私有文件和登录状态。

歌单、搜索、歌词与播放地址请求直接发到 `https://music.163.com`，不使用第三方代理。会话不发送到音频 CDN；音频和封面仅接受网易云允许域名的 HTTPS 地址。应用不记录 Cookie、临时播放地址或响应正文，也不把这些内容上传 GitHub。退出登录清除保存的会话，保留本地音乐、收藏、曲序、译文与队列记录；再次播放在线曲目需要有效登录。

本版本只读歌单，不提供收藏、订阅、增删歌曲等账号写操作。独立试用包不申请局域网权限或通知使用权。音频按需流式播放，没有整首离线下载入口；不上传本地音频或音乐文件夹。

## 范围与限制

- 使用网易云网站协议，属于兼容试用，并非网易云官方 Android SDK。服务端、登录风控或网站变化可能使功能暂时失效。
- 播放受当前账号的会员、购买、地区和版权权限约束；拒绝已识别的试听片段，不使用其他来源替换或绕过权限。无法播放时在 AMI 内提示。
- 歌单最多读取 1,000 张，单张歌单最多 20,000 个曲目 ID；详情按需分页。当前播放队列取点击时已载入的可用歌曲，最多 1,000 首。尚未载入的分页不会自动追加到正在播放的队列，需要先加载更多再选歌。
- 原版歌曲 ID 降低了按歌名误配歌词的风险，但服务端没有歌词或时间轴时，AMI 不能凭空补齐。新路径已验证《幸福》的滚动歌词，未宣称所有歌曲均有时间轴。
- 0.1.12 旧随播模式仍使用媒体会话和 LRCLIB。其繁简体匹配、纯文本候选优先级等问题已经研究，作为后续独立工作保留，本次没有修改这条匹配链路。
