# AMI 播放流程

当前应用 **0.2.11 / versionCode 33**，沿用单窗口播放页、Media3 服务与原有数据。封面回看、逐字歌词、推荐和专辑共享转场的实现见 [体验说明](LISTENING_EXPERIENCE.md)。

## 页面与时钟

专辑转场可中断、反向展开；目标页面立即接管触摸与无障碍操作。退出中的详情只参与绘制，不响应歌曲或红心，避免快速返回后点中旧页面。分页结果只回写原页面、原访问和原会话，固定请求偏移与前缀，避免迟到尾页截断专辑列表。

新选歌曲默认封面，同一首歌收起重开记住封面／歌词；读取歌词、收藏或更新译文不重置。封面缩放与播放页下拉仍可中断、反向拖回，系统栏配置按覆盖位置切换。

歌词和滑块共用明确跳转的目标预览，旧进度回执不能拉回新位置。手动翻阅暂停跟随，主动跳转恢复跟随。只保留当前歌曲的页面状态，歌词退出或应用退后台停止可见区域时钟。

逐字时间附加到原 LRC 行，不改变翻译索引。当前跟随行在绘制阶段读取播放进度并更新遮罩；普通行和译文不增加逐帧布局。

## 在线音源与失败处理

同一会话最多复用三个短期音源地址，只保存在内存。服务端明确提供有效期后才复用；从请求发出开始计时，扣除 30 秒余量，最多十分钟。没有有效期则按次解析。换账号立即清空，旧会话迟到的解析拒绝返回；实际播放出错使对应地址失效，下次重试重新解析。音质请求顺序及音频文件缓存规则保留。

最高音质优先。Android 客户端端点拒绝会话、未返回完整音源或网络失败时，先用同一账号尝试固定的第一方桌面端点，再尝试网页端点；本次解析不再重复请求已失败的客户端上下文。最多六次 v1 请求及一次原有 HQ 回退，通常取得最高档位后一次结束。真正的网页登录失效立即停止，不使用匿名会话、试听、替换音源或其他账号。

客户端版本字段与 AMI 版本分开，Android／桌面的 HTTP Cookie、加密 header 与 User-Agent 保持同一协议上下文。Cookie 百分号仅解码／编码一轮，不把原始加号当作空格。旧会话缺少 CSRF 时，只向网易云官网首页补齐一次校验 Cookie；不跟随重定向、不接受新的 MUSIC_U／匿名账号，账号变化时拒绝迟到结果。网页凭据保留原来的格式。

兼容音源 data 为数组或对象、单项省略 code 的响应；仍校验顶层状态、歌曲 ID、第一方 HTTPS 地址、完整时长及试听标记。没有把 VIP 等同于所有歌曲均有权限，也不以音质请求参数冒充实际返回档位。

失败时最多保留三个本会话内的简短诊断，仅含公开歌曲 ID、校验字段是否存在、固定请求路径／档位别名、返回数字状态与 URL／试听标记。错误提示可点「复制诊断」，播放页选项也只在本曲有诊断时显示复制入口；用户主动复制才加入 AMI／系统版本和机型，便于无电脑排查。不含 Cookie、播放地址、账号 ID、密钥或原始异常消息，不自动发送、不落盘。成功或换账号清除对应记录。

后续档位探测的接口拒绝或网络失败保留已有可用音源。媒体服务将错误映射为固定提示并传给本机界面，只保留一条当前歌曲错误；新增诊断仅记录错误码与异常类型，不复制含会话或签名地址的原始异常。

## 红心与账号同步

在线红心读取 `song/like/get`，显式点亮／取消提交 `radio/like`；两端沿用当前账号会话。状态 ID 使用已安装的持久集合，首次读取与手动刷新，写入立即反馈、成功确认、失败回退，同曲防重复。账号世代隔离旧请求的数据和错误；待处理动作至多 16 个，串行网络调用，不增加磁盘副本、周期任务或离线重试。

写入成功后修补已加载的「我喜欢」前缀与 nextOffset，并复用现有列表状态；网络分页换用调整后的 ID 快照。队列／catalog 身份不变，本地收藏与歌词时钟不受影响。

## 图片与邻曲

图片原图按需落盘、最近使用一周保留。少量小预览覆盖高清位图淘汰后的首帧等待；缓存命中绕过无关的新图下载锁。列表回看直接显示，新歌曲封面就绪后保留原有渐变。

Media3 稳定播放时先为下一首预加载目标约两秒音频，接近曲尾四十秒内提高到约五秒；优先保证当前歌曲加载。复用现有十秒检查点调整，不新增计时器、双播放器、交叉淡化或完整音频副本。暂停、缓冲、单曲循环及没有下一首时关闭额外池。格式与编码允许时由同一播放器衔接，不能保证任意音源都完全无间隙。

前台稳定播放后等待 700 ms，只准备下一首歌词、显示尺寸封面（最长 1280 px）和 48 px 取色结果；共享原有有上限的图片／歌词缓存。切歌、暂停、进入单曲循环或退后台取消准备，不预取整队，不生成翻译。取色样本不覆盖高清封面的内存键。预备配色在换歌同帧交给统一 360 ms 颜色转场，封面和标题保留旧内容至新内容接入。

## 播放模式与控制

底部主排依次为模式、上一首、播放／暂停、下一首、队列。播放键为唯一的大号实心主控，其余使用无独立边框的图标；歌词和翻译位于下方，拖动进度时滑块与轨道自然加粗，释放后收回。队列不再重复出现两次。

模式入口只保留三个标题：列表循环、单曲循环、随机播放。选择时同时设置 Media3 repeat／shuffle，避免两个独立按钮产生难以理解的组合。旧版顺序播放偏好读取时归入列表循环。

随机播放通过原生 ShuffleOrder 使用每轮索引排列，不改可见队列或专辑曲序。排列固定当前歌曲，优先避开最近八首，并尽量分散前两位歌手及上一张专辑；每步最多检查 24 个候选，复杂度为 O(24n)，即使同一歌手也能完成一轮。仅保留最近二十个歌曲 ID；切入随机、队列改变及自动循环到首项时重排，普通时间推进不重排。列表循环与单曲循环保持原曲序。

## 自动缓存与 FM

完整音频副本补齐和目录清理避开前台及播放缓冲，不增加周期唤醒。移动网络允许；近七天三次有效收听才进入候选，七天未听回收。音频上限沿用用户选择，单首 256 MiB，至少保留 1 GiB 可用空间，仅回收 AMI 在线副本。

FM 属于用户主动选择的播放来源，由播放服务在接近队尾时按事件获取一小批推荐并追加，不依赖界面常驻；暂停和退出本轮后停止，旧请求不能修改新队列。每日推荐进入普通队列。

## 长期聆听统计

播放服务沿用实际播放状态和十秒检查点，按单调时钟累计经过时间，按当时本地日期与小时分桶；暂停、换歌与结束时提交小批事务。保存每日歌曲时长、小时分布与曲目信息，独立于常听音频缓存的有效次数和淘汰策略。统计页按需生成有限快照，不触发本地曲库载入。详情见 [我的聆听](MY_LISTENING.md)。

## 柔和暂停与完整标题（0.2.7）

会话绑定 FadingPausePlayer，底层 ExoPlayer 仍负责解码、预加载、统计、音频焦点与 noisy。手动暂停用 SimpleBasePlayer 的未完成操作立即反馈暂停，底层增益在 360 ms 内按余弦包络归零后暂停并恢复原值。仅本次短渐弱安排主线程帧回调，不改变系统音量，也不留下后台轮询。立即继续、seek、换列表、stop、release 结束旧操作；底层被系统中断或自然停下时及时清理。开始时沿用现有播放快照，结束后照常保存实际位置。

标题区域独立动画尺寸，歌手名和控件随真实布局移动，不把整个信息列一起裁切。只在标题确实省略时支持原位展开，极长内容限制在 160 dp 的滑阅区；封面和歌词页共用状态，换歌重置。共享封面锚点、页面记忆和歌词时钟不改。
