# AMI 播放流程

当前应用 **0.2.2 / versionCode 24**，沿用单窗口播放页、Media3 服务与原有数据。封面回看、逐字歌词、推荐和专辑共享转场的本轮实现见 [体验说明](LISTENING_EXPERIENCE.md)。

## 页面与时钟

新选歌曲默认封面，同一首歌收起重开记住封面／歌词；读取歌词、收藏或更新译文不重置。封面缩放与播放页下拉仍可中断、反向拖回，系统栏配置按覆盖位置切换。

歌词和滑块共用明确跳转的目标预览，旧进度回执不能拉回新位置。手动翻阅暂停跟随，主动跳转恢复跟随。只保留当前歌曲的页面状态，歌词退出或应用退后台停止可见区域时钟。

逐字时间附加到原 LRC 行，不改变翻译索引。当前跟随行在绘制阶段读取播放进度并更新遮罩；普通行和译文不增加逐帧布局。

## 在线音源与失败处理

最高音质优先。客户端端点拒绝会话、未返回完整音源或网络失败时，尝试同一账号的固定第一方网页端点；本次解析不再重复请求已失败的客户端路径。最多五次 v1 请求及一次原有 HQ 回退，通常取得最高档位后一次结束。真正的网页登录失效立即停止，不使用匿名会话、试听、替换音源或其他账号。

后续档位探测的接口拒绝或网络失败保留已有可用音源。媒体服务将错误映射为固定提示并传给本机界面，只保留一条当前歌曲错误；新增诊断仅记录错误码与异常类型，不复制含会话或签名地址的原始异常。

## 红心与账号同步

在线红心读取 `song/like/get`，显式点亮／取消提交 `radio/like`；两端沿用当前账号会话。状态 ID 使用已安装的持久集合，首次读取与手动刷新，写入立即反馈、成功确认、失败回退，同曲防重复。账号世代隔离旧请求的数据和错误；待处理动作至多 16 个，串行网络调用，不增加磁盘副本、周期任务或离线重试。

写入成功后修补已加载的「我喜欢」前缀与 nextOffset，并复用现有列表状态；网络分页换用调整后的 ID 快照。队列／catalog 身份不变，本地收藏与歌词时钟不受影响。

## 图片与邻曲

图片原图按需落盘、最近使用一周保留。少量小预览覆盖高清位图淘汰后的首帧等待；缓存命中绕过无关的新图下载锁。列表回看直接显示，新歌曲封面就绪后保留原有渐变。

Media3 播放时使用目标约两秒的额外邻曲内存预加载，暂停、缓冲、单曲循环和单项队列关闭额外池。前台稳定播放后只少量准备下一首歌词，不生成翻译或提前抓取封面。

## 自动缓存与 FM

完整音频副本补齐和目录清理避开前台及播放缓冲，不增加周期唤醒。移动网络允许；近七天三次有效收听才进入候选，七天未听回收。音频上限沿用用户选择，单首 256 MiB，至少保留 1 GiB 可用空间，仅回收 AMI 在线副本。

FM 属于用户主动选择的播放来源，由播放服务在接近队尾时按事件获取一小批推荐并追加，不依赖界面常驻；暂停和退出本轮后停止，旧请求不能修改新队列。每日推荐进入普通队列。

## 长期聆听统计

播放服务沿用实际播放状态和十秒检查点，按单调时钟累计经过时间，按当时本地日期与小时分桶；暂停、换歌与结束时提交小批事务。保存每日歌曲时长、小时分布与曲目信息，独立于常听音频缓存的有效次数和淘汰策略。统计页按需生成有限快照，不触发本地曲库载入。详情见 [我的聆听](MY_LISTENING.md)。
