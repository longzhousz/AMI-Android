# 产品约束与行为文档

依据 0.2.7（`0dc00a0`）整理；本页保存长期取舍，具体实现和验证范围以专题与当前交接为准。行为改变时更新对应专题，不为每次发版改写本页。

- 主要面向 Android 与 vivo X300 / OriginOS 7，只用手机运行。优先简洁界面、自然且可中断的动效；允许合理前台绘制成本。后台和大曲库避免重复读取、主线程 IO、无意义的帧任务与周期轮询。
- 前台不增加翻译任务列表、生成进度、生成时间或模型记录；不恢复定时停止，不扩展未经要求的曲库管理。必要诊断只在用户明确复制时提供。
- 网易云是默认在线来源，保留本地音乐及已有数据。使用本应用官方 HTTPS 登录会话，不读取其他应用的 Cookie、密码或私有文件，不绕过歌曲、账号、地区或会员权限。音质按实际响应判断，不能以请求参数冒充结果。见 [使用说明](USER_GUIDE.md)。
- 曲库、红心、手动刷新、导入及缓存规则见 [使用说明](USER_GUIDE.md)。不要用刷新整库替代局部更新，不整库预取封面或音频，只清理 AMI 自己的副本。
- 控件、播放模式、暂停、页面记忆、共享封面与手势交接见 [播放流程](PLAYBACK_FLOW.md)。保留单一播放页窗口与连续封面锚点，不叠加错位的迷你播放器。
- 液态玻璃、光晕、原方形封面、迷你条缩略图圆角、独立队列弹层背景见 [材质说明](LIQUID_GLASS.md)。效果仅在可见且前台时绘制，不做逐帧 CPU 图片回读或跨窗口自采样。
- 封面回看、逐字歌词和推荐的资源边界见 [聆听体验](LISTENING_EXPERIENCE.md)；只使用真实歌词时间，保持已有行索引和当前播放队列。
- 「我的聆听」直接放在设置，不折叠；统计按需查询，后台仅复用播放检查点，不因清缓存、换账号或删歌丢失历史。见 [我的聆听](MY_LISTENING.md)。
- 翻译保留按需生成和手动选择，不因模型预设更新而覆盖手选或重新付费生成。默认不使用网易云自带译文。
- 自动更新只下载并核验本应用的最新正式安装包；进入设置且无其他覆盖窗口时才提示安装，不展示下载任务面板。见 [更新规则](APP_UPDATES.md)。
- vivo 原子岛仍有厂商兼容性边界；普通媒体通知、模板写入或模拟器通过不能证明真机接纳。见 [OriginOS](ORIGINOS_COMPATIBILITY.md)。
- 图标可编辑源图和原生资源生成方式见 [图标说明](../design/README.md)，不为桌面图标打包大尺寸 PNG。

历史 Windows 连接端、外部 App 随播和旧交付只作为兼容与追溯资料，见 [归档](archive/README.md)。
