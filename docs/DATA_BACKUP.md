# 个人数据备份与恢复

入口：**设置 → 存储与数据 → 备份与恢复**。导出和导入都使用 Android 系统文件选择器，无需电脑、存储全盘权限或 AMI 账号。

## 换机

1. 旧手机导出 JSON 文件，自行传到新手机。
2. 新手机安装 AMI，在相同入口选择「导入恢复」。
3. 在新手机重新登录网易云、重新填写翻译密钥；需要本地音乐时，再选择保存原音乐的文件夹并扫描。

备份包含周／月／年统计所需的数字汇总、曲目元数据、本地收藏与曲序、主题、翻译风格和模型选择、缓存上限、聆听周期、手动歌词关联、已保存译文和按歌曲 ID 保存的歌词。

不包含网易云 Cookie、API Key、Agent 令牌或调用权限、音乐与封面文件、音源 URL、原始文件路径、SAF 授权、播放队列和安装权限。网易云红心仍由服务器保存，重新登录后同步，不向服务器重放备份中的收藏操作。

JSON 未加密，包含听歌习惯及歌词；请保存在自己信任的位置。原始音频仍需自行保留。系统自动备份继续禁用，卸载前需要主动导出。

## 合并规则

- 保留当前数据；同一份文件重复导入不会重复增加时长。旧备份不能降低已记录的时长，多台设备各自新增的记录可以合并。
- 当前本地收藏、已有手动歌词和已缓存译文优先保留。已经恢复并由用户再次修改的收藏，不会在重复导入时被旧文件改回。
- 本地音乐不会生成无法播放的占位曲目。关联先保留在数据库，扫描完成后按原 ID，或唯一的标题、艺人、专辑、时长、CUE 起止及轨号组合匹配。重名且信息完全相同的多个文件不猜测关联；更换版本或修改元数据可能无法自动匹配。
- 原始数字统计完整保留。本地文件路径改变会产生新的歌曲身份，之后播放的本地文件可能另列为一首；网易云歌曲 ID 稳定，不受此影响。
- 恢复后的设置立即通过各自状态持有者更新；不会恢复网络调用授权、登录或密钥。

## 格式与资源边界

文件格式为 `ami.personal` / version 1。只接收固定的表和设置白名单，拒绝未知版本、重复键、不完整文件、非法计数及引用。最大 64 MiB，曲目／关联／译文各最多 50,000 条，日曲目与小时计数各最多 400,000 条，单个文本字段最多 2,000,000 字符；超限报错，不截断后保存。

导出在 IO 线程流式写临时文件，成功后复制到用户选定位置。导入先流式写入临时 SQLite 并完整校验，再在现有数据库的事务内合并。取消或合并异常回滚，临时文件在结束时清理，不保存第二套音频，也没有周期性备份或后台扫描。

本地数据库 schema 6 为统计计数增加安装来源 UUID。原有 schema 5 数值迁入本机来源 1；导入将来源 UUID 映射成本机整数索引。同来源、同日期和维度取较大累计值，不同来源在报告中求和。播放写入只增加本机来源，清空聆听历史时生成新的来源 UUID。继续使用数字汇总，不保存逐次听歌事件。

手动关联保存必要的历史歌曲 ID，查译文时尝试原缓存键，无需重新请求翻译。文件从未载入为完整内存对象，暂存数据库只用于本次操作。SQLite 合并与设置更新是先后执行的两步；设置仅由白名单意图方法写入。

验证范围与实际安装包见 [当前交接](LOCAL_HANDOFF.md)。
