# AMI 0.2.4 使用说明

专辑详情优先使用近期已载入的内容：内存缓存按估算 1 MiB 预算淘汰，最长七天，不因切换到另一张专辑就重新请求；进程回收或切换账号后按需重新读取。详情每次进入仍从顶部开始。需要最新内容时可手动下拉，详情页不显示转圈，刷新指示只保留在「曲库」「我喜欢」主页。

## 安装与登录

从 [最新发布](https://github.com/longzhousz/AMI-Android/releases/latest) 下载 `AMI-Android-0.2.4-online-preview.apk`。最低 Android 13（API 33），包名为 `com.longzhousz.ami.musicpreview`。

云端 0.1.14～0.2.3 使用相同包名与签名，直接覆盖更新可保留登录、设置、曲库和译文。其他包名的旧试用包可并存，数据不自动共享；本地自行签名的同包名安装通常不能直接覆盖。不要为解决签名冲突卸载或清除已有应用，卸载会丢失应用私有数据。

在 AMI 打开「登录网易云」，由自己在网易云官方 HTTPS 页面输入账号、密码或验证码，完成后点击「完成登录」。之后运行只需要手机，无需网易云 App 后台播放、电脑服务、开放平台应用或私钥。账号管理位于设置。

AMI 使用网站／客户端兼容协议，不是网易云官方 Android SDK；登录、接口和音源可用性可能随服务端变化。播放遵守账号、会员、购买、地区及歌曲权限，不使用替换音源或绕过权限。

## 曲库与我喜欢

- 「曲库」仅用封面网格展示收藏的专辑和自己创建的歌单；「我喜欢」展示红心歌曲，顶部是最近 30 首的封面墙，不足 30 首按实际数量展示。
- 切换标签保留已载入内容和位置，不自动重新刷新。下拉或双击对应导航图标才主动刷新。
- 曲库刷新随机重排卡片；至少两张卡片时首张更换。专辑／歌单内部曲序和正在播放的队列保持不变。
- 顶部搜索按钮点击后展开搜索；歌曲列表接近底部按需续载。当前队列取选歌时已经载入的可用曲目，最多 1,000 首，后续分页不自动追加。
- 点击「发现音乐」图标选择私人 FM 或每日推荐，直接使用原来的播放页开听。私人 FM 按服务端结果在队尾续接，切换其他歌曲后结束本轮 FM。
- 底部悬浮导航只有曲库、我喜欢、设置三个图标。专辑和歌曲行展示完整方形原图；迷你播放器缩略图保留圆角。

## 红心与网易云

在线播放歌曲在封面页、歌词页、搜索／专辑列表和队列里都能点亮或取消红心；「我喜欢」歌曲行不再重复显示红心，操作写入 AMI 当前登录的网易云账号。在原版 App 刷新「我喜欢的音乐」可核对；原版的改动也可通过 AMI 手动下拉刷新同步回来。

按钮即时反馈，等待响应时防止同曲重复提交；失败恢复之前的状态并提示。成功后更新已载入的「我喜欢」，保留当前歌曲、播放队列和列表位置；切换标签不自动刷新歌单。红心需要网络，不在后台积攒离线写入。状态只保留一份内存快照；本地音乐仍使用原有本地收藏。

## 材质与光晕

0.2.4 沿用开源 Backdrop 液态玻璃，悬浮栏、设置卡片、菜单和对话框使用折射、高光与柔和阴影。播放主控采用中央实心播放键与四个无框图标，靠尺寸和留白区分主次。专辑详情和播放页的光晕随封面取色缓慢流动，退到后台或页面被覆盖时停止。完整光学效果要求 Android 13 及以上，不需要 root 或额外插件。见 [材质说明](LIQUID_GLASS.md)。

## 封面与歌词

新选歌曲默认显示封面，重新点当前歌曲或切换曲目也回到封面。点击大封面或歌词图标切到歌词，点击小封面可放大；同一首歌收起再打开会保留刚才的页面。

下拉页头收起播放页，拖动途中可以反向返回。新封面未加载完成时保留上一张成功画面，准备好后再渐变替换；真正失败时显示占位图。

浏览过的曲库封面回滚时先直接显示已保留的轻量预览，再由高清图片接上；内存不足时系统仍可释放缓存。点击专辑封面会连续展开为详情封面，返回缩回原卡片并保留网格位置。

点歌词或拖动进度条可以跳转，歌词与滑块共用目标预览，避免旧进度把歌词拉回。手动翻阅暂停跟随，点击「回到当前句」恢复；无时间轴歌词保留正文浏览。

网易云提供有效逐字时间轴时，当前句会按演唱逐字／词亮起；没有对应数据的歌沿用普通歌词。无需增加开关，暂停与手动浏览保持原来的使用方式。

默认不使用网易云自带译文，保留 AMI 已生成的翻译。在设置配置 DeepSeek API Key、模型和风格后，可主动翻译或重新翻译。默认自动跟随最新 Flash，也可选择 Pro 或手动模型；刷新预设不覆盖手动选择，不自动重译旧歌词。翻译只发送歌词，不上传音频、封面或本地路径。

## 播放控制与随机

底部主排依次为模式、上一首、播放／暂停、下一首、队列，下方保留歌词和翻译两个图标。点击模式选择顺序播放（播完停止）、列表循环（播完从头继续）、单曲循环、随机播放，图标分别为直箭头、循环、带 1 循环、交叉箭头。

随机尽量避开近期歌曲、打散相邻歌手和专辑，每轮依原生索引排列，保留可见队列。切回顺序或列表循环仍使用原曲序。

平时为下一首准备目标约两秒音频，曲尾提高到约五秒；前台同时准备下一首封面、配色与歌词，播放封面即使命中内存也保留渐变。只准备下一首，沿用已有缓存上限，不新增音频副本或周期任务；网络和编码可能仍造成间隙。

## 音质

优先请求账号有权限的 **高清臻音 → Hi-Res → 无损 → 极高**，根据服务器实际返回的档位、编码和码率判断结果，不把请求参数当成实际音质。已识别的试听片段不播放。

部分会话不被客户端音源端点接受时，AMI 会用同一账号尝试网页端点，必要时使用原有极高音质接口；已取得的可用音源会保留。播放失败会区分登录过期、只有试听、接口拒绝、音频服务器、网络和解码错误。若官方 App 可以完整播放而 AMI 仍失败，请记录歌曲名及完整提示；无需提供密码、验证码或 Cookie。

歌词页右上角「歌词选项」显示当前音源档位；尚未取得音源时为待确认。这个值描述音源，耳机实际输出、蓝牙编码、系统重采样及空间渲染另受设备限制，不能据此保证复现官方客户端全部音效。

## 存储与自动缓存

封面通常在请求显示时下载原图；稳定播放时仅提前准备下一首的封面。列表、播放页与背景取色共用原始文件，内存命中也会续期。最近使用一周内保留，不提前抓取整库；过期目录回收让开前台操作，系统仍可自行清理应用缓存。

近七天至少三次有效收听的在线歌曲进入完整音源缓存候选。一次连续播放累计实际出声 30 秒算有效收听；短曲按半首、至少三秒计算。同次播放只计一次，暂停、缓冲及拖动不增加时长。

后台通过系统任务少量补齐，每批至多两首，允许 Wi-Fi 和移动网络。新任务等待界面退后台、播放器完成加载、没有导入且电量与存储正常；进行中的副本可继续经历普通补缓冲，真正缓冲不足或返回前台时优先让路。未完成或校验失败的文件不用于播放。

已有完整缓存时后续优先本地播放，歌曲身份、歌词与界面保持一致；损坏或缺失时尝试回到同歌曲的在线音源。七天没有有效收听的副本在后续维护中回收，不专门为清理周期唤醒手机。

在「设置 → 存储与隐私 → 常听歌曲缓存上限」选择 256 MB、512 MB、1／2／4／8 GB，默认 512 MB。降低上限先回收较久未听的在线副本；正在播放的文件受保护。单首最多 256 MiB，并保留至少 1 GiB 剩余空间，不会为了减少占用而主动降低音质。

自动回收仅管理 AMI 自己的在线缓存，不删除导入源文件或 NCM 转换结果。退出／切换账号清理对应在线音频缓存，不跨账号复用。它不等于完整离线曲库，歌单和歌词仍有各自的加载条件。

## 我的聆听

设置页直接显示「我的聆听」，点击进入周、月、年纵向图鉴。首次默认本月，之后记住周期类型；重新进入查看当前周期。周从星期一开始，支持翻看往期、点击日期选择历史，以及下拉手动刷新。

展示实际听歌时长、歌曲数、听歌天数、最长连续天数，以及时长趋势、听歌日历、歌曲前十、歌手占比、专辑偏好、星期与小时热力图、初遇与重逢比例。点击图表查看数值，不切换歌曲。

只统计更新后 AMI 内的实际播放，在线与本地缓存合并；有可靠网易云 ID 的本地歌曲也会归到同一首。暂停、缓冲、拖动进度不计时；倍速播放十分钟仍记十分钟。合作曲优先归主艺人，缺少结构化信息时保留原署名。“初遇”指首次在 AMI 记录，并非新发行的歌曲。

长期保存数字汇总与去重后的曲目信息，封面沿用现有缓存；不保存播放流水、报表图片或额外音频。清缓存、删歌曲、换账号会保留记录。页面选项可查看统计说明，或确认后清除全部聆听记录；歌曲、账号和译文保留。记录仅在本机，异常退出可能遗漏最后约十秒。

## 本地音乐与数据

本地音乐入口位于「设置 → 浏览本地音乐」，按需载入，原有文件夹授权、收藏、曲序和译文保留。

支持 MP3、M4A、FLAC、WAV、OGG、OPUS、AAC 等设备可解码格式；经典 `CTENFDAM` NCM 在应用内转换，不改动源文件，其他或新加密容器不保证可用。CUE 通过虚拟曲目播放，不切割原文件；支持 UTF-8／GB18030 的 LRC。重新扫描保留已有用户数据。

本地封面依次尝试可解码的音频内嵌图片、NCM 容器图片、同目录 `cover`／`folder`／`front` 图片，缺图 NCM 再按元数据中的准确图片地址补全，不按歌名搜索。导入网易云数字歌词时，先自行把歌词文件复制到普通可授权目录；Android 11 及以上不能直接读取其他应用的 `Android/data`。

网易云会话与 DeepSeek API Key 使用 Android Keystore 加密，不写日志，不读取其他应用的登录状态。应用无广告、分析上报或 AMI 云账号；禁用系统备份，卸载会清除私有数据。更多开发和签名规则见 [本地开发](LOCAL_DEVELOPMENT.md)。

## 应用更新

从 0.2.3 开始，启动后自动检查 GitHub 新版并在后台下载，进入设置才询问是否安装。选择「稍后」可以继续使用，下载的包会保留；下次启动后可以再次询问。首次安装可能需要在系统页面允许 AMI 安装应用。升级后自动清理旧安装包。详见 [更新规则](APP_UPDATES.md)。
