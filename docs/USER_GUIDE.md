# AMI 0.1.17 使用说明

## 安装与登录

从 [最新发布](https://github.com/longzhousz/AMI-Android/releases/latest) 下载 `AMI-Android-0.1.17-online-preview.apk`。最低 Android 8.0，包名为 `com.longzhousz.ami.musicpreview`。

云端 0.1.14～0.1.16 使用相同包名与签名，直接覆盖更新可保留登录、设置、曲库和译文。其他包名的旧试用包可并存，数据不自动共享；本地自行签名的同包名安装通常不能直接覆盖。不要为解决签名冲突卸载或清除已有应用，卸载会丢失应用私有数据。

在 AMI 打开「登录网易云」，由自己在网易云官方 HTTPS 页面输入账号、密码或验证码，完成后点击「完成登录」。之后运行只需要手机，无需网易云 App 后台播放、电脑服务、开放平台应用或私钥。账号管理位于设置。

AMI 使用网站／客户端兼容协议，不是网易云官方 Android SDK；登录、接口和音源可用性可能随服务端变化。播放遵守账号、会员、购买、地区及歌曲权限，不使用替换音源或绕过权限。

## 曲库与我喜欢

- 「曲库」仅用封面网格展示收藏的专辑和自己创建的歌单；「我喜欢」展示红心歌曲。
- 切换标签保留已载入内容和位置，不自动重新刷新。下拉或双击对应导航图标才主动刷新。
- 曲库刷新随机重排卡片；至少两张卡片时首张更换。专辑／歌单内部曲序和正在播放的队列保持不变。
- 顶部搜索按钮点击后展开搜索；歌曲列表接近底部按需续载。当前队列取选歌时已经载入的可用曲目，最多 1,000 首，后续分页不自动追加。
- 底部悬浮导航只有曲库、我喜欢、设置三个图标。专辑和歌曲行展示完整方形原图；迷你播放器缩略图保留圆角。

## 封面与歌词

新选歌曲默认显示封面，重新点当前歌曲或切换曲目也回到封面。点击大封面或歌词图标切到歌词，点击小封面可放大；同一首歌收起再打开会保留刚才的页面。

下拉页头收起播放页，拖动途中可以反向返回。新封面未加载完成时保留上一张成功画面，准备好后再渐变替换；真正失败时显示占位图。

点歌词或拖动进度条可以跳转，歌词与滑块共用目标预览，避免旧进度把歌词拉回。手动翻阅暂停跟随，点击「回到当前句」恢复；无时间轴歌词保留正文浏览。

默认不使用网易云自带译文，保留 AMI 已生成的翻译。在设置配置 DeepSeek API Key、模型和风格后，可主动翻译或重新翻译。默认自动跟随最新 Flash，也可选择 Pro 或手动模型；刷新预设不覆盖手动选择，不自动重译旧歌词。翻译只发送歌词，不上传音频、封面或本地路径。

## 音质

优先请求账号有权限的 **高清臻音 → Hi-Res → 无损 → 极高**，根据服务器实际返回的档位、编码和码率判断结果，不把请求参数当成实际音质。已识别的试听片段不播放。

歌词页右上角「歌词选项」显示当前音源档位；尚未取得音源时为待确认。这个值描述音源，耳机实际输出、蓝牙编码、系统重采样及空间渲染另受设备限制，不能据此保证复现官方客户端全部音效。

## 存储与自动缓存

封面只在请求显示时下载原图，列表、播放页与背景取色共用原始文件，内存命中也会续期。最近使用一周内保留，不提前抓取整库；过期目录回收让开前台操作，系统仍可自行清理应用缓存。

近七天至少三次有效收听的在线歌曲进入完整音源缓存候选。一次连续播放累计实际出声 30 秒算有效收听；短曲按半首、至少三秒计算。同次播放只计一次，暂停、缓冲及拖动不增加时长。

后台通过系统任务少量补齐，每批至多两首，允许 Wi-Fi 和移动网络。新任务等待界面退后台、播放器完成加载、没有导入且电量与存储正常；进行中的副本可继续经历普通补缓冲，真正缓冲不足或返回前台时优先让路。未完成或校验失败的文件不用于播放。

已有完整缓存时后续优先本地播放，歌曲身份、歌词与界面保持一致；损坏或缺失时尝试回到同歌曲的在线音源。七天没有有效收听的副本在后续维护中回收，不专门为清理周期唤醒手机。

在「设置 → 存储与隐私 → 常听歌曲缓存上限」选择 256 MB、512 MB、1／2／4／8 GB，默认 512 MB。降低上限先回收较久未听的在线副本；正在播放的文件受保护。单首最多 256 MiB，并保留至少 1 GiB 剩余空间，不会为了减少占用而主动降低音质。

自动回收仅管理 AMI 自己的在线缓存，不删除导入源文件或 NCM 转换结果。退出／切换账号清理对应在线音频缓存，不跨账号复用。它不等于完整离线曲库，歌单和歌词仍有各自的加载条件。

## 本地音乐与数据

本地音乐入口位于「设置 → 浏览本地音乐」，按需载入，原有文件夹授权、收藏、曲序和译文保留。

支持 MP3、M4A、FLAC、WAV、OGG、OPUS、AAC 等设备可解码格式；经典 `CTENFDAM` NCM 在应用内转换，不改动源文件，其他或新加密容器不保证可用。CUE 通过虚拟曲目播放，不切割原文件；支持 UTF-8／GB18030 的 LRC。重新扫描保留已有用户数据。

本地封面依次尝试可解码的音频内嵌图片、NCM 容器图片、同目录 `cover`／`folder`／`front` 图片，缺图 NCM 再按元数据中的准确图片地址补全，不按歌名搜索。导入网易云数字歌词时，先自行把歌词文件复制到普通可授权目录；Android 11 及以上不能直接读取其他应用的 `Android/data`。

网易云会话与 DeepSeek API Key 使用 Android Keystore 加密，不写日志，不读取其他应用的登录状态。应用无广告、分析上报或 AMI 云账号；禁用系统备份，卸载会清除私有数据。更多开发和签名规则见 [本地开发](LOCAL_DEVELOPMENT.md)。
