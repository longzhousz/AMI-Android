# 液态玻璃与封面光晕

0.2.4 使用 [Kyant0/AndroidLiquidGlass](https://github.com/Kyant0/AndroidLiquidGlass/tree/1.0.6) 的原生 Android **Backdrop 1.0.6**，依赖 `io.github.kyant0:backdrop:1.0.6`。保留 Apache-2.0 许可，光学算法由上游提供，AMI 负责材质参数、页面取色和交互整合。不是苹果官方组件，也不依赖厂商系统插件。

## 选型

| 候选 | 能力与决定 |
| --- | --- |
| [Backdrop](https://kyant.gitbook.io/backdrop) | RenderEffect 模糊、AGSL 镜片折射、色散、高光和阴影；原生 1.0.6 与 Compose 1.10.3 对齐，本轮采用。 |
| [Haze / haze-glass](https://github.com/chrisbanes/haze) | 2.x 已有真实玻璃折射；所查 2.0.0 Android 发布依赖 Kotlin 2.4.20 / Compose 1.12，涉及更广工具链迁移，本轮不采用。 |
| [Miuix](https://github.com/compose-miuix-ui/miuix) | 社区 HyperOS 风格完整组件库，适合整体采用其设计体系；AMI 保留现有导航与交互，不引入另一套 UI 系统。不是小米官方 SDK。 |
| [ColorOS16 LiquidGlass](https://github.com/AYwlilwYA/ColorOS16-LiquidGlass) | 面向 ColorOS 16 的 LSPosed 系统修改模块，需要 root；不适用于 AMI。其光学算法同样引用 Kyant，本轮直接采用上游库。 |

选型核对日期：2026-10-30。固定 1.0.6 tag 的提交 `896a94a3ade1cc1a940b92365f942a34971fecda`；不引入要求 Compose 1.12 的新版 KMP 分支。

## 显示与资源

- **最低 Android 13 / API 33**。AGSL 镜片折射从此版本可用，按用户要求以完整效果为优先，不维护低版本替代皮肤。既有低版本安装不会被清理，但不能安装此更新。
- 悬浮导航与迷你播放条采样下方真实页面，内容滚动时跟随折射；选中标签由可中断弹簧移动。页面内卡片和控件采样独立背景，避免采样自己的玻璃输出产生反馈。文字与原始封面保持清晰。
- 搜索、设置分组、聆听图鉴卡片、菜单、对话框和队列使用统一材质。播放主排用唯一的大号实心主控及四个无框图标建立层级，歌词／翻译位于下方，避免为每个按钮套玻璃圆环。歌曲行保持轻量，避免为每行红心单独运行一套光学效果。
- 专辑详情与播放页的背景从现有封面缓存取 48 px 小图，在 IO 线程采样色彩；最多记忆 32 份配色。不保留高清背景位图，不做逐帧 CPU 截图、像素回读或额外图片下载副本。
- 三团柔和光晕以 26 秒周期连续流动，换封面时颜色交叉过渡。仅 Canvas 绘制读取动画时钟，文字、曲库和歌词数据不跟随重组。应用不在 RESUMED 状态、页面被完整播放器覆盖或退出页面时停止动画；不新增后台轮询。
- 「我喜欢」采用沉浸式深色背景，顶部封面统一角度、紧密拼接并渐隐至正文，不再放入白色玻璃相框。展示已载入红心歌单中最近的 **30 首**封面，沿用歌单顺序与现有图片缓存，不从无序红心 ID 集合取顺序，不整库抓图。歌曲不足 30 首则按实际数量展示；同步红心后修补封面墙，分页继续沿用原逻辑。
- 「我喜欢」歌曲行不再显示重复的红心按钮；播放页、搜索、专辑和队列保留喜欢／取消喜欢及网易云同步。
- 专辑封面仍是完整方形原图，迷你播放条缩略图保留 9 dp 圆角。没有新增材质设置、进度面板或独立图片数据库。

## 验证边界

新增原生测试检查封面墙条数与顺序、缓存复用、红心更新、后续分页，检查真实硬件渲染路径中的玻璃随源更新、浅深主题操作，以及光晕在可见时运动、被覆盖时静止。仪器测试与截图来自专用模拟器和合成曲目，不代表 vivo X300 的真实帧率、温度、功耗或原子岛结果。最终通过的代码提交与运行链接见 [当前交接](LOCAL_HANDOFF.md)。

既有修复：在线专辑每次打开使用新的访问状态，封面与详情从顶部展开；曲库网格位置仍保留。播放队列移除跨窗口玻璃采样，弹层自己持有配色背景及控件所需的玻璃源，使用播放器深色。原生弹层负责滑动、返回与收起，关闭动画被手势打断后释放状态；不对整个移动弹层套全屏折射。

0.2.4 在前台稳定播放时只准备下一首的封面和配色，复用有上限的既有缓存；48 px 取色请求不覆盖高清封面内存键。四个颜色通道共用 360 ms 转场，播放封面缓存命中时也渐变，曲库回看仍立即显示。
