# AMI Android 0.1.3 预览版

面向 Android 17，最低 Android 8.0。包名与签名延续 0.1.2，可直接覆盖安装，保留曲库、收藏、设置及歌词缓存。

## 沉浸式歌词

- 有歌词时，点底部迷你播放器即可进入歌词页；底部「封面 / 歌词」切换视图。
- 大字号、柔和景深、温暖白色当前句、封面取色渐变背景，延续 AMI 的留白与阅读层次。
- 长句和双语完整换行。当前句平滑跟随；手动滑动后停留在浏览位置，点「回到当前句」恢复。
- 点击带时间轴的句子可以跳转；无时间轴歌词可自由阅读。
- 「译文」显示/隐藏已有翻译，不触发网络；需要重新翻译时使用右上角「歌词选项 → 重新翻译」。没有译文时，底部提供「翻译」。
- 横屏分栏，放大字体时保留清晰文字；旧版 Android 使用淡出层次。
- 播放页顶部可下拉收起，歌词区域可独立浏览；进度条收细，保留拖动跳转。

## 网易云数字歌词

将 `Android/data/com.netease.cloudmusic/files/LrcDownload` 复制或导出到 `Music/AMI-Lyrics` 等普通目录，然后在「设置 → 网易云歌词 → 选择歌词文件夹」导入。按 NCM 歌曲 ID 自动关联，数字文件无需改名。

歌词、译文与 NCM 转换音频保存在本机。单曲手动选择歌词文件、恢复自动匹配、队列、随机 / 循环和定时停止均保留。

预览 APK 使用与前版一致的开发签名，不是正式发行签名。请优先覆盖安装；卸载会清除本机数据。
